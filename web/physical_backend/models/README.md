# 预下载的 PaddleDetection 模型目录

将以下模型权重放在本目录:

- ppyoloe_crowdhuman/
  - 行人检测 (PP-YOLOE-l)
- bytetrack/
  - 多目标跟踪
- pphuman_attribute/
  - 行人 26 类属性
- pphuman_action/
  - 行人行为识别 (摔倒/打架/抽烟/打电话)
- picodet_s_320_coco/
  - 通用物体检测 (人/车/商品)
- clip_vit_b32/
  - 零样本商品识别

模型下载脚本见 `web/physical_backend/scripts/download_models.sh`（阶段 C 补齐）
